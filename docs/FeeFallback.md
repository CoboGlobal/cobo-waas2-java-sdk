

# FeeFallback

|**fallback** | **Boolean** | Whether the estimated transaction fee is generated by Cobo&#39;s fallback mechanism. Check &#x60;fallback_reason&#x60; and use the value with caution. - &#x60;false&#x60;: The returned fee values are generated by a normal fee estimation.  |  [optional] |
|**fallbackReason** | **String** | The reason why Cobo&#39;s fallback mechanism was used, such as the error message returned by the blockchain node. This property is returned only when &#x60;fallback&#x60; is &#x60;true&#x60;.  |  [optional] |
